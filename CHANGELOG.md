Strudel Samples changelog

2026-11-24, v2026.11.24. Added a pad board page that loads every clip from the map. Pick clips from a library menu, set each pad's start point by dragging its waveform or typing seconds, and turn on chain mode so each pad plays the next one when it ends. The board layout saves itself in the browser, and the site root opens the board.

2026-11-10, v2026.11.10. Added a word puller that grabs every short clip of one word. The first pull was the word hello, trimmed tight with misses dropped and a hello supercut added. Every sample is now named by its words, show, episode, and clip id, and a catalog lists them all.

2026-11-09, v2026.11.09. Created a sample pack for the Strudel music tool, with a map that lets Strudel load clips straight from this repo. Added short spoken clips and a puller script that fetches them, with a run log and a fallback when the first host fails. Candidate clips were sorted, trimmed, and joined into the final set.
